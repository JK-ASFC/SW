PRÉREQUIS

Burger Quiz est une application web locale. Elle fonctionne dans un navigateur moderne sans installation, mais nécessite un serveur HTTP local pour que les fichiers se chargent correctement (vidéos, sons, images).

Option 1 — Python (recommandé)

Python est gratuit et disponible sur python.org. Une fois installé, ouvrez un terminal dans le dossier du projet et lancez :

python -m http.server 8000

Puis ouvrez votre navigateur à l'adresse http://localhost:8000.

💡
Raccourci Windows Double-cliquez sur start_server.bat s'il existe dans le dossier, sinon créez un fichier texte avec python -m http.server 8000 && pause et renommez-le en start_server.bat.

Option 2 — Extension VS Code

Installez l'extension Live Server dans Visual Studio Code, puis cliquez sur "Go Live" en bas à droite. Le navigateur s'ouvre automatiquement.

Option 3 — XAMPP / WAMP

Placez le dossier du projet dans le répertoire htdocs (XAMPP) ou www (WAMP) et accédez via http://localhost/burger/.

⚠️
Ne pas ouvrir directement le fichier HTML Ouvrir index.html en double-cliquant (protocole file://) bloque le chargement des vidéos et des sons à cause des restrictions de sécurité du navigateur.

Navigateur compatible

  • Google Chrome ou Microsoft Edge — recommandés, meilleure compatibilité vidéo
  • Firefox — compatible mais certains formats vidéo peuvent poser problème
  • Safari — compatible mais nécessite des formats MP4 H.264

Formats de médias supportés

  • Vidéo : MP4 (H.264), WebM
  • Audio : MP3, OGG, WAV, M4A
  • Image : JPG, PNG, GIF, WebP, SVG
  • Document : PDF

ADMIN — LISTES

L'interface d'administration est accessible via le bouton Admin de l'accueil ou en appuyant sur A pendant le jeu.

Gestion des listes

Le bouton Liste en haut permet de gérer plusieurs listes de questions indépendantes (ex : "Saison 1", "Spécial Noël"). Chaque liste a son propre ensemble de slides.

  • Cliquer sur le widget Liste ▾ pour ouvrir le panneau de gestion
  • + Liste — créer une nouvelle liste vide
  • Cliquer sur une liste pour la rendre active (étoile ★)
  • Modifier le nom directement dans le champ
  • Supprimer une liste avec le bouton ✕ (les slides restent dans la base)

Gestion des slides

  • + Nouveau slide — ajoute un slide à la liste active
  • Cliquer sur un slide dans la liste de gauche pour l'éditer
  • Glisser-déposer pour réordonner les slides
  • Bouton ✕ rouge sur chaque slide pour le supprimer
  • Les modifications sont sauvegardées automatiquement à chaque changement de champ

Bibliothèque de médias

Le bouton 🖼 Médias ouvre la galerie de tous les fichiers stockés (images, vidéos, audio). Vous pouvez y supprimer des médias inutilisés.

ADMIN — TYPES DE SLIDES

Chaque slide a un type qui détermine son affichage et son comportement pendant le jeu.

Type Nom Description
🎬 V Vidéo Lecture d'une vidéo en plein écran. Utile pour le générique d'intro ou des extraits.
🍟 N Nuggets Question à choix multiple (4 réponses A/B/C/D). La bonne réponse est révélée avec Espace.
🧂 S Sel ou Poivre Question vrai/faux. SEL = vrai, POIVRE = faux.
🖼️ I Image Affiche une image avec titre et question optionnels.
🍔 M Menu Question avec sous-questions (sous-menu déroulant). Navigation dans les sous-questions avec ← →.
📋 L Liste menus Liste de 3 menus à sélectionner. Chaque menu peut être joué indépendamment.
➕ A Addition Round addition — affiche des éléments à additionner.
💀 B Burger Mort Slide spécial qui déclenche le Burger de la Mort. Contient la vidéo d'intro BDM.
👥 C Candidats Présentation des deux candidats (nom, photo, description). Révélation en deux temps avec Espace.
🎁 G Cadeau Slide de révélation du cadeau BDM. Affiché automatiquement si l'équipe réussit le BDM.
🎲 T Toss Tirage au sort / duel entre deux candidats. Espace révèle le gagnant.

Attacher un média à un slide

La plupart des types acceptent un média (image, vidéo, audio, PDF). Glissez-déposez le fichier dans la zone pointillée ou cliquez pour parcourir. Le fichier est stocké dans le navigateur (IndexedDB) — aucun serveur de fichiers nécessaire.

ADMIN — BURGER DE LA MORT

Le Burger de la Mort est un défi optionnel en fin d'émission. Le bouton 💀 Listes BDM ouvre le gestionnaire.

Créer une liste BDM

  • Cliquer + Nouvelle liste
  • Nommer la liste (ex : "Liste A", "Spéciale")
  • Saisir jusqu'à 10 questions dans les champs numérotés
  • Cliquer ★ Définir active pour choisir la liste qui sera utilisée au prochain BDM
💡
Conseil Préparez 2–3 listes à l'avance. Si une équipe échoue, vous pouvez basculer sur une autre liste pour l'équipe adverse sans rejouer les mêmes questions.

Slide déclencheur

Créez un slide de type 💀 B dans votre liste principale. Il contient la vidéo d'intro du BDM. Quand ce slide apparaît pendant le jeu, l'animateur appuie sur → pour lancer la vidéo, puis → à nouveau pour entrer dans les questions.

ADMIN — PARAMÈTRES

Le bouton ⚙ Paramètres permet de configurer les médias globaux de l'émission.

ParamètreRôle
Musique BDM Musique jouée en boucle pendant les questions du Burger de la Mort.
Musique de victoire Musique déclenchée quand une équipe atteint 25 points.
Générique de fin Vidéo diffusée après le BDM réussi (générique façon émission TV).
Retour au calme Titre et message affichés après le générique sur l'écran de retour au calme (avec sonomètre).

Pour chaque média, glissez-déposez le fichier ou cliquez pour sélectionner. Le fichier est stocké dans la base de données du navigateur.

ADMIN — EXPORT / IMPORT

Exporter

Le bouton ⬇ Exporter génère un fichier .json contenant :

  • Tous les slides de toutes les listes
  • Toutes les listes (noms, IDs)
  • Toutes les listes BDM et leurs questions
  • Tous les médias (images, vidéos, sons) encodés en base64
  • Les paramètres (musiques, générique, retour au calme)
⚠️
Sauvegardez régulièrement ! Le stockage navigateur peut être effacé si vous videz le cache ou réinitialisez le navigateur. L'export JSON est votre seule sauvegarde externe.

Importer

Le bouton ⬆ Importer restaure un fichier JSON précédemment exporté. Tous les slides, listes et médias sont rechargés. Les données existantes sont remplacées.

🔴
Attention L'import écrase les données actuelles. Exportez d'abord si vous souhaitez conserver la session en cours.

Import CSV

Il est également possible d'importer une liste de questions au format CSV pour créer rapidement des slides Nuggets en masse.

JEU — MODES SPÉCIAUX

Mode Candidats

Le slide 👥 C affiche les deux candidats en deux temps :

  1. Premier appui Espace — révèle le premier candidat seul
  2. Second appui Espace — révèle le second candidat

Mode Toss

Le slide 🎲 T gère le duel d'entrée. Espace révèle le résultat du tirage au sort.

Mode Victoire à 25 pts

Automatique dès qu'un score atteint 25. Confettis aux couleurs de l'équipe + musique de victoire (11 secondes). Une confirmation apparaît ensuite pour officialiser la victoire.

Vidéo intro BDM

Après la dernière question, récap s'affiche automatiquement

→
L'animateur décide du résultat

Si RÉUSSI ✅

  • Confettis + musique de joie
  • Affichage du slide Cadeau (🎁)
  • Bouton Autre équipe : relancer un BDM avec une autre liste pour l'équipe adverse
  • Bouton Générique de fin : lancer la vidéo de générique
  • Bouton Terminer : fermer la fenêtre BDM

Si ÉCHOUÉ ❌

  • Un sélecteur de liste apparaît
  • Choisir une autre liste BDM pour l'équipe adverse
  • Le BDM repart depuis le début avec les nouvelles questions

Générique de fin

La vidéo configurée en paramètres se lance en plein écran. Appuyer → ou Espace pour passer en mode Retour au calme.

Retour au calme (sonomètre)

Écran minimaliste avec un sonomètre en temps réel utilisant le micro de l'ordinateur :

  • Vert — niveau correct (≤ 40 dB) : les invités sont calmes
  • Orange — légèrement fort (41–60 dB)
  • Rouge — trop fort (> 60 dB)

Cliquer sur Activer le micro pour démarrer la mesure. Le navigateur demandera l'autorisation d'accès au microphone.

JEU — FIN DE SOIRÉE

Après le générique et le retour au calme, cliquer Terminer affiche l'écran de fin :

MERCI À TOUS
pour votre participation
BONNE NUIT !

Un clic ou n'importe quelle touche ferme cet écran et vous ramène au jeu.

STOCKAGE

Burger Quiz utilise deux mécanismes de stockage navigateur, sans aucun serveur de base de données :

MécanismeCe qui y est stockéLimite indicative
IndexedDB Slides, médias (images, vidéos, sons) en binaire Plusieurs Go selon navigateur
LocalStorage Listes, listes BDM, scores, paramètres retour au calme ~5 Mo
⚠️
Ces données sont liées au navigateur et au domaine Vider le cache, changer de navigateur ou accéder depuis une autre machine efface toutes les données. Exportez régulièrement en JSON.

Libérer de l'espace

Si le navigateur signale un manque d'espace : ouvrez l'admin → 🖼 Médias → supprimez les fichiers non utilisés.
